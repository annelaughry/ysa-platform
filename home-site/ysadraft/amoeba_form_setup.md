# Project Amoeba — Google Form Setup Guide

Create the form at forms.google.com → Blank form.
Title: **Project Amoeba Design Submission**
Description: *Submit your original mascot design for Project Amoeba — the YSA design competition. Read the rules on the YSA website before submitting. All designs must be your own original work (no AI generation).*

---

## Questions (copy exactly)

**Q1 — Full Name**
Type: Short answer | Required: YES

**Q2 — Email Address**
Type: Short answer | Required: YES
Description: *We'll use this to contact you if you're selected.*

**Q3 — Age / Grade**
Type: Short answer | Required: NO
Description: *Optional — helps us recognize submissions from different age groups.*

**Q4 — Are you a current YSA member?**
Type: Multiple choice | Required: YES
Options:
- Yes, I'm a Global STEM Ambassador
- Yes, I'm a STEM Explorer
- No, but I'm interested in joining
- No, I'm submitting as a community member

**Q6 — Design Title**
Type: Short answer | Required: YES
Description: *Give your mascot a name or title.*

**Q7 — Design Description**
Type: Paragraph | Required: YES
Description: *Describe your design in at least 3 sentences. What does it represent? How does it capture the amoeba concept (adaptable, always growing, community-first)? What makes it YSA-esque?*
Validation: Minimum character count → 150 characters

**Q8 — Upload Your Design**
Type: File upload | Required: YES
Allowed file types: Images (JPG, PNG, SVG), PDF
Max file size: 10MB
Description: *Upload your design as a PNG, JPG, SVG, or PDF. Make sure it's a clean, high-quality version.*

**Q9 — Process Notes**
Type: Paragraph | Required: NO
Description: *Briefly describe how you made it — tools used, how long it took, anything you want the judges to know about your process. Optional but encouraged.*

**Q10 — Confirmation (REQUIRED)**
Type: Checkboxes | Required: YES (must select both)
Options:
- I confirm this design is my own original work and was NOT generated by AI tools
- I confirm this design is scalable and can work at multiple sizes (from phone screen to banner)

**Q11 — How did you hear about Project Amoeba?**
Type: Multiple choice | Required: NO
Options:
- YSA website
- Social media
- A friend / fellow ambassador
- YSA summit or event
- Email from YSA
- Other

## After creating the form:

1. Click **Send** (top right)
2. Click the **<>** (Embed) icon
3. Copy the `src=` URL from the iframe code
4. Open `ysadraft/amoeba.html` in a text editor
5. Find the comment that says `PASTE_GOOGLE_FORM_URL_HERE`
6. Replace that placeholder with the copied URL
7. Delete the `<div class="form-placeholder">` block above the commented-out iframe
8. Uncomment the `<iframe>` block (remove the `<!--` and `-->`)

## Connect to Google Sheets (for reviewing submissions):
- In Google Forms → Responses tab → Click the green Sheets icon
- This creates a spreadsheet that auto-fills with every submission
- Add a column called "Status" and "Notes" for your review process
- You can then sort/filter by Q4 (YSA membership) to prioritize ambassador submissions
